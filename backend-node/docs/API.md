# Milk World Backend API

## 1. Общая информация

Backend проекта Milk World построен на Node.js, Express, TypeScript и Supabase.

**Базовый URL локального сервера:**

`http://localhost:3000/api`

Формат запросов и ответов: JSON.

Для защищённых запросов используется Bearer Token.

Заголовок авторизации:

`Authorization: Bearer YOUR_ACCESS_TOKEN`

Заголовок для JSON-запросов:

`Content-Type: application/json`

---

## 2. Авторизация

### Вход в систему

**POST** `/auth/login`

Вход пользователя в систему.

Пример запроса:

```json
{
  "email": "admin@example.com",
  "password": "password"
}
```

В ответе возвращаются данные пользователя, access token и refresh token.

---

## 3. Каталог товаров

Базовый путь: `/products`

### Получить список товаров

**GET** `/products`

Получение списка товаров.

### Получить товар по ID

**GET** `/products/:id`

Получение информации о конкретном товаре.

### Создать товар

**POST** `/products`

Доступ: admin, editor.

### Обновить товар

**PATCH** `/products/:id`

Доступ: admin, editor.

### Удалить товар

**DELETE** `/products/:id`

Доступ: admin.

### Поиск товаров

**GET** `/products/search`

Публичный поиск товаров с поддержкой фильтрации, сортировки и пагинации.

## 4. Подкатегории

Базовый путь: `/subcategories`

### Получить список подкатегорий

**GET** `/subcategories`

### Получить подкатегории по категории

**GET** `/subcategories?categoryId=1`

### Создать подкатегорию

**POST** `/subcategories`

Доступ: admin, editor.

Пример запроса:

```json
{
  "name": "Молоко",
  "category_id": 1
}
```

### Изменить подкатегорию

**PATCH** `/subcategories/:id`

Доступ: admin, editor.

### Удалить подкатегорию

**DELETE** `/subcategories/:id`

Доступ: admin.

## 5. Новости

Базовый путь: `/news`

### Получить опубликованные новости

**GET** `/news`

Поддерживаемые параметры:

- `search` — поиск по заголовку.
- `categoryId` — фильтр по категории.
- `year` — фильтр по году публикации.

Пример:

`GET /news?search=производство&categoryId=1&year=2026`

### Получить новость по ID

**GET** `/news/:id`

Возвращает только опубликованные новости.

### Получить новость по slug

**GET** `/news/slug/:slug`

Возвращает опубликованную новость по уникальному URL.

### Получить все новости для админ-панели

**GET** `/news/admin/all`

Доступ: admin, editor.

Возвращает все новости, включая неопубликованные.

### Создать новость

**POST** `/news`

Доступ: admin, editor.

Пример запроса:

```json
{
  "category_id": 1,
  "title": "Открытие нового производства Milk World",
  "slug": "otkrytie-novogo-proizvodstva",
  "content": "Milk World продолжает развиваться.",
  "image_url": "https://example.com/news.jpg",
  "is_published": false
}
```

### Обновить новость

**PATCH** `/news/:id`

Доступ: admin, editor.

### Опубликовать новость

**PATCH** `/news/:id/publish`

Доступ: admin, editor.

### Снять новость с публикации

**PATCH** `/news/:id/unpublish`

Доступ: admin, editor.

### Удалить новость

**DELETE** `/news/:id`

Доступ: admin.

---

## 6. Категории новостей

### Получить категории

**GET** `/news/categories`

### Создать категорию

**POST** `/news/categories`

Доступ: admin, editor.

Пример запроса:

```json
{
  "name": "Новости компании"
}
```

### Удалить категорию

**DELETE** `/news/categories/:id`

Доступ: admin.

При удалении категории связанные новости сохраняются, а их `category_id` становится `null`.

## 8. Роли и права доступа

| Действие | Admin | Editor | Без авторизации |
|---|---|---|---|
| Просмотр публичных товаров | Да | Да | Да |
| Создание товара | Да | Да | Нет |
| Изменение товара | Да | Да | Нет |
| Удаление товара | Да | Нет | Нет |
| Просмотр публичных новостей | Да | Да | Да |
| Создание новости | Да | Да | Нет |
| Редактирование новости | Да | Да | Нет |
| Публикация новости | Да | Да | Нет |
| Удаление новости | Да | Нет | Нет |
| Управление категориями новостей | Да | Создание | Нет |

## 9. Коды ответов HTTP

| Код | Значение |
|---|---|
| 200 | Успешный запрос |
| 201 | Ресурс создан |
| 400 | Ошибка запроса |
| 401 | Необходима авторизация |
| 403 | Недостаточно прав |
| 404 | Ресурс не найден |
| 500 | Внутренняя ошибка сервера |
