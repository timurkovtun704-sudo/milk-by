# База данных

СУБД: PostgreSQL.

Планируемые сущности:
- Product — товар.
- Category — категория и иерархия категорий.
- ProductCharacteristic — характеристики товара.
- Packaging — варианты фасовки.
- News — публикации.
- User — учётные записи пользователей и администраторов.
- Translation — переводы контента либо локализованные поля.

Окончательную схему, связи, ограничения и стратегию миграций Backend-команда должна согласовать до реализации каталога и CMS.
