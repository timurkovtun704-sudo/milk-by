# API — предварительный контракт

Базовый адрес локального Backend: `http://localhost:8080/api`.

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/health` | Проверка доступности Backend |
| GET | `/products` | Получение списка товаров |
| GET | `/products/{id}` | Получение товара |
| GET | `/categories` | Получение категорий |
| GET | `/news` | Получение новостей |
| POST | `/feedback` | Отправка заявки |

Кроме `/health`, перечисленные endpoints являются планом, а не реализованными методами. Перед разработкой согласовать параметры пагинации, фильтров, сортировки, языковой код и формат ошибок.
